Requirements

  • StretchSense Hand Engine: Login to your account page on http://www.stretchsense.com/my-account  or email support@stretchsense.com for details.
  • Autodesk Maya: https://www.autodesk.co.nz/products/maya/overview
  • Operating System: Windows 10
  • Recorded Data from Hand Engine on Full Body.
 

Retargeting

  1. Import target asset into Maya
  2. Set up in T-pose with Hands in Paddle L Pose
  1. Create a control rig/define skeleton
  1. Import Full Body FBX recording from HE, it should already come ready with the control rig setup (Use a namespace when importing to prevent issues with bone names that are shared)
  1. For the target Character set the source to StretchSense (If you play the animation now you should see both the StretchSense asset and target asset move in synchronization.)
  1. Set the timeline of the take to match the animation (saves time during baking)
  1. Then Bake the animation to the skeleton. Now we should have hand data on the target Asset.

 

Exporting hand animation data

  1. Go to the Layers tab in Maya
  1. In the layers tab select Anim, then add layers by selecting this button (layer with the circle). This will create two layers the base animation and AnimLayer1. You can delete AnimLayer1 at this stage.
  1. In the left side hierarchy select the bones we are interested in (all fingers excluding the metacarpal bones) then right-click on the Base animation object and select Extra Selected Objects. This will create a new layer with just the finger-keyed data in it.
  1. Right-click on the newly created layer and export and save this file.

 

Merging the hand and body data

  1. Create a new scene in Maya
  2. Assuming you already have the body motion on the same target asset import this into Maya
  3. Drag and drop in the previously saved Hand animation layer. It should appear in the layer stack we looked at previously and should appear as an overwrite setting meaning it will overwrite the base (body) animation where keys are present (finger only)
  4. If the Body data and hand data are both synchronized with the timecode it should require no further changes and you can skip to Step 9, if not you can use the Time Editor to drag the finger or body keys into line.
  5. Select root bone (or just hand bones if these are the only ones you want to update).
  6. Open time editor (Windows>Animation Editors>Time Editor).

 
  1. Select “Add selected content from scene”
  1. Click and drag the animation to adjust where in the timeline the animation should occur
  1. Once the animations are lined up you should be able to see them running by pressing the play icon in Maya.
  2. To combine the hand and body animations, select the Base animation (body) and hand animation in the layer view. Right-click and select merge. This should combine the two key tracks into a single base layer and the separate hand layer will be removed.
