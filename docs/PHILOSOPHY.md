# Atlas Philosophy

> Every piece of knowledge should exist only once.

Knowledge should never be trapped in a person’s head, buried in an email, duplicated across documents, or lost when someone leaves the company.

Atlas exists to ensure that knowledge is:

* Captured once.
* Organised automatically.
* Connected to related knowledge.
* Version controlled.
* Searchable by everyone.
* Reusable everywhere.
* Preserved for the future.

*"People create knowledge. Atlas remembers it.*
